# Expense Tracker (Mk)

A simple expense tracker for students and young adults in Malawi who want to see where their Kwacha goes each month.

## How to run
1. Download or clone this repository.
2. Open `index.html` in any modern browser (no server, install or database needed).
   Or view it online: 'https://github.com/AttieTimah05/expense-tracker'

## Features
- **Expenses view:** add an expense (category, amount, date), see the running total, delete entries.
- **Summary view:** see spending per category as bars, filtered by month.
- Clear error and success messages; data is saved in the browser with `localStorage`.

## Tech
HTML, CSS and vanilla JavaScript.
